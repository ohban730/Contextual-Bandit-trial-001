# semantic.py の説明書

## ひとことでいうと
「最近の興味」と「そのチャンネルのいつもの内容」が、
**意味としてどれくらい近いか**を点数にする係です。
`embeddings.py`が作った数字の並び(ベクトル)を実際に使う場所です。

## なにをしているところ？

`embeddings.py`が、動画タイトルを「意味を表す数字の並び」に
変換してくれました。このファイルは、その数字の並びを使って
実際に「近さくらべ」をします。

たとえるなら、地図の上に「最近の自分がいる場所」と
「それぞれのチャンネルがいつもいる場所」をピンで刺して、
2つのピンの距離が近いほど「意味が近い」と判定するイメージです。
(実際には方角の近さ=向きの近さで測っています)

## 出てくる主な道具

### `_mean_vector(vectors)`
複数の数字の並び(ベクトル)を平均する係です。たとえば、あるチャンネルの
動画が3本あったら、その3本分のベクトルを足して3で割り、
「このチャンネルの平均的な内容の向き」を1本のベクトルにまとめます。

### `_cosine_similarity(a, b)`
2つのベクトル`a`と`b`が「どれくらい同じ方向を向いているか」を
測るものさしです。これを**コサイン類似度**と呼びます。

- まったく同じ方向 → 1に近い(とても似ている)
- 直角(まったく関係ない方向) → 0に近い
- 正反対の方向 → -1に近い

`np.dot(a, b)`(内積)を、それぞれのベクトルの「長さ」で割ることで
計算しています。

### `build_recent_interest_vector(history_df, embedding_df, window_days)`
直近`window_days`日間(初期設定14日)に見た動画のベクトルを平均して、
「今のあなたの興味の向き」を1本のベクトルにまとめます。

### `add_semantic_scores(channel_df, history_df, embedding_df, window_days)`
「今の興味の向き」と「各チャンネルのいつもの向き」のコサイン類似度を
計算し、`semantic_score`という点数(0〜1)としてチャンネルの表に
くっつけます。

## 具体的な流れの例

1. 「今の興味の向き」ベクトルが `recent_vector` として求まる
2. チャンネルAの動画タイトルの平均ベクトルが `recent_vector` と
   ほぼ同じ方向 → コサイン類似度が0.9くらいになる
3. `semantic_score = (0.9 + 1) / 2 = 0.95`(0〜1の範囲に変換)
4. チャンネルBはまったく関係ない話題で、コサイン類似度が0くらい
   → `semantic_score = (0 + 1) / 2 = 0.5`

コサイン類似度はもともと-1〜1の範囲なので、`(similarity + 1) / 2`という
式で0〜1の範囲に引き伸ばして、他のスコアと同じものさしで
比べられるようにしています。

## もっと知りたい人へ
- `np.linalg.norm(a)`: ベクトル`a`の「長さ(大きさ)」を計算します。
- `+ 1e-9`: 万が一ベクトルの長さが0になってしまったとき、
  0で割り算してエラーになるのを防ぐための、ごく小さな安全マージンです。

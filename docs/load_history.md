# load_history.py の説明書

## ひとことでいうと
Googleからダウンロードした「視聴履歴のファイル(watch-history.json)」を、
プログラムが扱いやすい**きれいな表(ひょう)**に変える係です。

## なにをしているところ？

GoogleTakeoutというサービスでダウンロードできる視聴履歴ファイルは、
実はけっこう「ごちゃごちゃ」しています。たとえば

- 広告を再生しただけの記録や、検索した記録もまざっている
- タイトルの前や後ろに `"Watched "` や `"を視聴しました"` のような
  余計な言葉がくっついている
- 動画のURLの中にIDが埋めこまれている(取り出さないと使えない)

このファイルは、そんな「生(なま)のデータ」を1件ずつチェックして、
本当に動画を見た記録だけを選び、きれいな表(DataFrame)に整えます。

## 出てくる主な道具

### `_extract_video_id(title_url)`
動画のURL(例: `https://www.youtube.com/watch?v=ABC123`)から、
`v=` の後ろの部分(`ABC123`)だけを取り出す係です。
`urlparse` と `parse_qs` というPythonの部品を使って、URLを
「ドメイン」「クエリ(? のあとの部分)」などに分解しています。

### `_clean_title(title)`
タイトルの前や後ろについている余計な飾り言葉
(`"Watched "` や `"を視聴しました"`)を取りのぞく係です。

### `load_watch_history(path=None)`
メインの関数です。JSONファイルを読みこんで、1件ずつ
「動画を見た記録かどうか」をチェックしながら、表の1行分の
データ(辞書)を作っていきます。最後に `pandas` の `DataFrame` という
「エクセルの表のようなもの」にまとめて返します。

## 具体的な流れの例

もとのデータの1件がこんな感じだったとします。

```json
{
  "header": "YouTube",
  "title": "Watched とある動画のタイトル",
  "titleUrl": "https://www.youtube.com/watch?v=xyz789",
  "subtitles": [{"name": "とあるチャンネル", "url": "..."}],
  "time": "2026-01-01T10:00:00Z"
}
```

この関数を通すと、表の1行はこうなります。

| video_title | video_id | channel_name | watched_at |
|---|---|---|---|
| とある動画のタイトル | xyz789 | とあるチャンネル | 2026-01-01 10:00:00+00:00 |

`"Watched "` が消えていて、URLから`video_id`だけが取り出されているのが
わかりますね。

## もっと知りたい人へ
- `pandas.DataFrame`: たくさんの行と列を持つ「表」を扱うためのPythonの
  ライブラリ。エクセルの表をプログラムであつかうイメージです。
- `datetime.fromisoformat`: 文字列(`"2026-01-01T10:00:00Z"`)を、
  プログラムが計算に使える「日時」の形に変換します。

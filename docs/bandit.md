# bandit.py の説明書

## ひとことでいうと
「どのチャンネルをおすすめするか」を選び、あなたの
「good」「bad」の評価から**すこしずつ好みを学んでいく**、
このプログラムの頭脳(のうみそ)にあたる部分です。

## なにをしているところ？(たとえ話)

くじ引き機を想像してください。最初はどの箱にアタリが多いか
まったくわからないので、ほぼランダムに選ぶしかありません。
でも「この箱を選んだらアタリだった」「この箱はハズレだった」を
何度もくり返すうちに、だんだん「アタリが出やすい箱」がわかってきます。

この`LinearThompsonSamplingBandit`クラスは、まさにそのくじ引き機です。
違うのは、箱そのものだけでなく「箱の特徴(久しぶり度・好きだった度など)」
から**アタリやすさを予想する式**を、フィードバックのたびに
少しずつ賢く更新していくところです。

## 出てくる主な用語・道具

### `theta`(シータ)って何?
`theta`は、「久しぶり度が高いほど+◯◯点」「ジャンルが合っているほど
+◯◯点」というような、**それぞれの特徴にどれくらいの重要度があるか**
を表す数字の並びです。これがまさに「あなたの好み」をモデル化した
中身です。ロボットは`theta`を直接知ることはできず、フィードバックを
通じて少しずつ推測していきます。

### `self.A` と `self.b` は何のためにあるの?
`theta`をピタリと言い当てることはできないので、ロボットは
「たぶんこのあたりの値だろう」という**確信度つきの予想**を
`A`と`b`という2つの数字のかたまり(行列・ベクトル)に
覚えさせておきます。フィードバックが増えるほど、この2つの中身が
書き換わり、`theta`の予想がだんだん正確になっていきます。

- 初めて実行したとき(フィードバックがまだ0件のとき)、この`A`と`b`は
  どんな初期値になっているでしょうか?　`_load_state()`の中身
  (`self.lambda_ * np.eye(self.d)` と `np.zeros(self.d)`)を、
  実際に手を動かして確認してみましょう。`np.eye`(単位行列)と
  `np.zeros`(ゼロだけの配列)がそれぞれ何を作る関数か調べてみると、
  「データが1件もないとき、ロボットの頭の中がどんな状態か」が
  わかるはずです。

### `theta_mean`(プロパティ)
`np.linalg.inv(self.A) @ self.b` という式で、「今のところ一番
それらしいtheta」を計算します。`@property`という書き方のおかげで、
`bandit.theta_mean()`ではなく`bandit.theta_mean`と、
まるで変数のように呼び出せます。

### `sample_scores(context_matrix)`
これがThompson Samplingの心臓部です。「一番それらしいtheta」
(`theta_mean`)だけを使うのではなく、そのまわりの
「ありえそうな別のtheta」もくじ引きのように1回サンプリング
(`np.random.multivariate_normal`)してから、それぞれの候補チャンネルの
点数を計算します。

なぜわざわざランダム性を混ぜるのでしょう?　もし毎回
「一番自信のある予想」だけで選んでいると、たまたま最初に
高得点だったチャンネルばかり選び続けてしまい、他の可能性のある
チャンネルを試すチャンスを失ってしまいます。ランダム性を混ぜることで、
**「今まで学んだ好みを活かす(活用)」と「まだよく知らない
チャンネルにもチャンスをあげる(探索)」のバランス**を取っています。

データが少ないうち(`A`が初期値に近い)ほど、`A_inv`が大きくなり、
サンプリングのばらつき幅が大きくなるので、選び方はよりランダムに
近づきます。フィードバックが貯まるほど、ばらつきが小さくなり、
学習した好みに沿った選び方に変わっていきます。

### `update(context, reward)`
フィードバックを1件受け取るたびに、`A`と`b`を書き換えて
「学習」する関数です。

- `x = np.append(context, 1.0)`: 特徴量の最後に「1.0」を1個追加します。
  これは`theta`の中に「バイアス項(下駄をはかせる分)」を含めるための
  お決まりのテクニックです。
- `self.A += np.outer(x, x)`: `np.outer`は「外積」を計算し、
  行列を作ります。これを`A`に足しこむことで、「このような特徴を持つ
  候補を1件見た」という情報を積み重ねていきます。
- `self.b += reward * x`: 評価が良かった(`reward=1.0`)ときは
  `x`をそのまま足し、悪かった(`reward=0.0`)ときは何も足しません。
- 最後に`_save_state()`でファイルに保存し、次にプログラムを
  起動したときも学習した内容が消えないようにします。

### `save_pending` / `load_pending` / `clear_pending`
「今どのチャンネルを提案中で、まだ評価待ちか」を一時的に
覚えておくための仕組みです。あなたが`--feedback good`のように
評価コマンドを打ったとき、「さっき提案したのはどのチャンネルだったか」
を思い出すために使われます。

### `log_feedback` / `already_judged_channels`
評価した結果を、`suggestion_log.json`という「評価ずみノート」に
記録していきます。

- `bad`評価をつけたチャンネルは、**ずっと**もう提案されません。
- `good`評価をつけたチャンネルは、`GOOD_COOLDOWN_DAYS`(30日)の間だけ
  お休みし、それを過ぎるとまた候補に戻ってきます
  (「良かったけど、しばらく見てないから、また提案してもいいかな」
  というイメージです)。
- 同じチャンネルに複数回の評価履歴があっても、一番新しい評価だけが
  使われます(`latest_by_channel`で上書きしているのがポイントです)。

## もっと知りたい人へ
- `np.random.multivariate_normal(mean, cov)`: 「多変量正規分布」という、
  複数の数字がセットで、ある中心のまわりにばらついて出てくる
  乱数を生成します。`mean`が中心、`cov`がばらつきの大きさです。
- `np.outer(x, x)`: ベクトル`x`を使って、`x`のすべての組み合わせの
  掛け算を並べた行列を作ります(線形回帰の理論で出てくる
  「計画行列の転置×計画行列」という考え方の元になっています)。
- この仕組み全体は「線形回帰 + Thompson Sampling」と呼ばれる、
  文脈付きバンディット(contextual bandit)のアルゴリズムの一種です。
